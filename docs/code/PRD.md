# 代码块

post 里的 code_block 经 lark-cli 渲染成独立成行的 markdown 围栏，larkim 按代码块画。

## 展示

- 围栏行本身不显示，语言标记取自开围栏（`JSON`、`SQL`、`JAVA`、`BASH`、`PLAIN_TEXT`）
- 左侧一条细竖线 `▏` 加右对齐行号，行号宽度按块内最大行号
- 语法高亮用 chroma，调色板按终端明暗在 `github` / `github-dark` 之间选
- chroma 没有对应 lexer 的语言（含飞书的 `PLAIN_TEXT`）不着色，纯文本渲染
- 纯文本 token 不涂前景色，保留终端自身前景；不涂背景，避免和选中底色打架

## 排版

- 代码行按窗口宽度截断并以 `…` 收尾，不折行：折行会毁掉语句结构，完整内容用 `y` 复制
- 窗口窄到放不下行号槽时，行号槽让位给代码
- 闭围栏前飞书留的空行丢弃
- 没有闭围栏的块一直延伸到正文结尾

## 不处理

- 卡片（interactive）里的围栏：lark-cli 把它拼在句子中间、前后都没有换行，不成行的围栏不当代码块
- 行内 `code` 片段
